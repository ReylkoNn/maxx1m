# Развёртывание Max1m на российском VPS в 1 команду (без VPN) и сборка `Max1m.exe`

Данное руководство описывает запуск полностью автономного узла **Max1m** для команды (5–50 человек) на любом российском VPS (Selectel, Timeweb Cloud, Рег.ру, FirstVDS, Aeza и др.) без зарубежных облаков и без VPN.

---

## 1. Требования к серверу и DNS

1. **VPS в РФ**: Ubuntu 22.04 / 24.04 или Debian 12 (`1–2 vCPU`, `2 GB RAM`, `20 GB NVMe`).
2. **Доменное имя**: направьте `A`-запись (например, `chat.company.ru`) на публичный IPv4 вашего VPS.
   - *Опционально (для жёстких корпоративных прокси, где открыт только TCP 443)*: выделите второй IP/поддомен `turn.company.ru` и передайте `--turn-domain turn.company.ru --turn-tls-443`. На обычном одно-IP сервере `Caddy` занимает `443/tcp` под HTTPS/WSS, а `coturn` автоматически обслуживает `3478/udp`, `3478/tcp` и `5349/tcp` (TLS).
3. **Открытые порты фаервола VPS**:
   - `80/tcp`, `443/tcp`, `443/udp` — HTTPS / TLS 1.3 и WebSocket
   - `3478/udp`, `3478/tcp`, `5349/tcp` — STUN / TURN / TURNS медиа-ретранслятор
   - `49160-49300/udp` — WebRTC медиа-потоки голоса и демонстрации экрана

---

## 2. Запуск узла в 1 команду

Подключитесь к серверу по SSH и выполните:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> /opt/max1m
cd /opt/max1m/deploy
sudo ./bootstrap_vps.sh --domain chat.company.ru --invites 10 --title "Наш Офис"
```

Скрипт `bootstrap_vps.sh` автоматически:
1. Установит Docker и Docker Compose (если они ещё не установлены).
2. Сгенерирует криптостойкие 256-битные ключи `SECRET_KEY` и `TURN_SHARED_SECRET` (`chmod 600 .env`).
3. Соберёт изолированный `max1m-backend` (`read_only`, `cap_drop: ALL`, без логов IP-адресов `--no-access-log`), `max1m-caddy` (TLS 1.3, `log output discard`) и `max1m-coturn` (с защитой от SSRF по локальным подсетям).
4. Дождётся выпуска TLS-сертификата, вычислит `sha256/...` **TLS SPKI Pin** открытого ключа сервера и выпустит 10 одноразовых инвайт-кодов.
5. Выведет в консоль готовые персональные строки подключения **`max1m-join://...`** для каждого сотрудника!

### Выпуск новых инвайтов позже

```bash
cd /opt/max1m/deploy
INV=$(sudo docker compose exec -T backend python create_invite.py | grep -Eo 'MAX1M-[A-Z0-9-]{19}')
python3 generate_join_link.py --server https://chat.company.ru --invite "$INV" --title "Наш Офис"
```

## 3. Подключение сотрудников в 1 клик (`max1m-join://`)

1. Отправьте коллеге архив `Max1m-Windows-x64.zip` и его персональную строку `max1m-join://...`.
2. Коллега запускает `Max1m.exe`, вставляет строку в поле **«Быстрое подключение команды (`max1m-join://`)»** на стартовом экране и нажимает **«Применить»**:
   - Адрес сервера прописывается автоматически;
   - **TLS SPKI Pin закрепляется до первого сетевого пакета** (защита от DPI/MITM подмены сертификата без ручной настройки переменных окружения Windows);
   - Одноразовый инвайт-код подставляется в форму регистрации.
3. После входа рекомендуем каждому сотруднику открыть **Настройки → Безопасность**:
   - Включить **Локальный сейф Argon2id** (изымает ключи из системного Keyring Windows в зашифрованный `vault.enc` в RAM, включает автоблокировку и опциональный **Duress PIN** экстренного стирания);
   - Сверить **60-значный Код безопасности** с коллегами голосом в групповой комнате (достаточно сверить 2–3 пятёрки цифр).

---

## 4. Бесшовная ротация TLS-сертификата сервера

Если вы меняете ключевую пару TLS-сертификата:
1. Вычислите SPKI Pin нового ключа: `python3 deploy/generate_join_link.py --server https://chat.company.ru --cert-pem new_cert.pem`.
2. Добавьте резервный пин в **Настройки → Безопасность → Добавить пин** (клиент поддерживает до 4 одновременных SPKI-пинов на узел).

---

## 5. Сборка автономного `Max1m.exe` для Windows 10/11

На любой рабочей станции Windows 10/11 (x64) с установленным Python 3.11:

```powershell
powershell -ExecutionPolicy Bypass -File .\packaging\build_windows.ps1
```

Готовый портативный архив не требующий установки Python появится по пути:
`packaging\dist\Max1m-Windows-x64.zip` (внутри `Max1m\Max1m.exe`).
